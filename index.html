Module 1

JavaScript Basics

Variables, Data Types & Operators — the building blocks of every JS program.

📝

Variables

Variables are containers for storing data values. JavaScript has three ways to declare them:

  • var — Function-scoped, can be re-declared (legacy)
  • let — Block-scoped, can be reassigned
  • const — Block-scoped, cannot be reassigned
🌍 Real World

Think of variables like labeled boxes — const is a sealed box, let is a box you can swap the contents of.

🔢

Data Types

JavaScript has 8 data types. The most common primitive types:

  • String — "Hello World"
  • Number — 42, 3.14
  • Boolean — true / false
  • undefined — declared but not assigned
  • null — intentional absence of value
  • Object — { key: "value" }
  • Array — [1, 2, 3]
🌍 Real World

A user profile uses strings for names, numbers for age, booleans for active status, and objects to group everything together.

➕

Operators

Operators perform operations on variables and values:

  • Arithmetic: + - * / % **
  • Assignment: = += -= *=
  • Comparison: == === != !== > <
  • Logical: && || !
  • Ternary: condition ? a : b
🌍 Real World

=== checks both value AND type. 5 === "5" is false — always prefer strict equality!

Module 2

                
Functions

                
Reusable blocks of code — from declarations to arrow functions and callbacks.

            


            

                

                    

                        📌
                        
Function Declaration

                    

                    
The classic way to define a reusable block of code. Function declarations are hoisted, meaning they can be called before they're defined.

                    

                        
function greet(name) {
  return `Hello, ${name}!`;
}
console.log(greet("Alice")); // Hello, Alice!

                    

                    

                        🌍 Real World
                        
Like a recipe — you define it once and follow (call) it whenever you want to cook that dish.

                    

                


                

                    

                        ➡️
                        
Arrow Functions

                    

                    
A concise ES6 syntax. Arrow functions don't have their own this binding.

                    

                        
const add = (a, b) => a + b;

const greet = name => `Hi, ${name}!`;

const getUser = () => ({
  name: "Alice",
  age: 25
});

                    

                    

                        🌍 Real World
                        
Arrow functions are used heavily in array methods: users.filter(u => u.active)

                    

                


                

                    

                        🔄
                        
Callbacks

                    

                    
A callback is a function passed as an argument to another function. It runs after the parent function completes its task.

                    

                        
function fetchData(callback) {
  setTimeout(() => {
    callback("Data loaded!");
  }, 1000);
}

fetchData(result => {
  console.log(result);
});

                    

                    

                        🌍 Real World
                        
Like placing an order and giving your phone number — the restaurant calls you back when it's ready.

                    

                


                

                    

                        👻
                        
Anonymous & IIFE

                    

                    
Anonymous functions have no name. IIFE (Immediately Invoked Function Expression) runs right after creation.

                    

                        
// Anonymous — used as callback
setTimeout(function() {
  console.log("Runs after 1s");
}, 1000);

// IIFE — runs immediately
(function() {
  console.log("I run right away!");
})();

                    

                    

                        🌍 Real World
                        
IIFEs are used to create isolated scopes — common in older libraries to avoid polluting the global namespace.

Module 3

                
Object-Oriented Programming

                
Objects, Classes & Inheritance — model the real world with structured code.

            


            

                

                    

                        📦
                        
Objects

                    

                    
Objects store related data and functions together as key-value pairs. They're the core of JavaScript.

                    

                        
const car = {
  brand: "Tesla",
  model: "Model 3",
  year: 2024,
  start() {
    return `${this.brand} ${this.model} started!`;
  }
};

console.log(car.start());

                    

                    

                        🌍 Real World
                        
A user profile is an object: properties hold data (name, email), methods perform actions (login, updateProfile).

                    

                


                

                    

                        🏭
                        
Classes

                    

                    
Classes are blueprints for creating objects. They use constructor for initialization and can have methods.

                    

                        
class Animal {
  constructor(name, sound) {
    this.name = name;
    this.sound = sound;
  }

  speak() {
    return `${this.name} says ${this.sound}!`;
  }
}

const dog = new Animal("Dog", "Woof");
console.log(dog.speak());

                    

                    

                        🌍 Real World
                        
A class is like a cookie cutter — the class defines the shape, each object is a unique cookie made from it.

                    

                


                

                    

                        🧬
                        
Inheritance

                    

                    
Use extends to create a child class that inherits from a parent. Use super() to call the parent constructor.

                    

                        
class Vehicle {
  constructor(brand) {
    this.brand = brand;
  }
  describe() {
    return `Brand: ${this.brand}`;
  }
}

class Car extends Vehicle {
  constructor(brand, model) {
    super(brand);
    this.model = model;
  }
  describe() {
    return `${super.describe()}, Model: ${this.model}`;
  }
}

const myCar = new Car("Tesla", "Model S");
console.log(myCar.describe());

                    

                    

                        🌍 Real World
                        
In a game: Character → Warrior, Mage. Common traits are shared; unique abilities are added per class.

Module 4

                
Promises

                
Handle asynchronous operations elegantly with resolve, reject & chaining.

            


            

                

                    

                        🤝
                        
Promise Basics

                    

                    
A Promise represents a value that may be available now, later, or never. It has three states:

                    
    
                        
  • Pending — Initial state, waiting
    • 
                        
  • Fulfilled — Operation succeeded (resolve)
    • 
                        
  • Rejected — Operation failed (reject)
    • 
                    

                    

                        
const myPromise = new Promise((resolve, reject) => {
  const success = true;
  if (success) resolve("It worked! ✅");
  else reject("Something went wrong ❌");
});

myPromise
  .then(result => console.log(result))
  .catch(error => console.log(error));

                    

                    

                        🌍 Real World
                        
Like ordering food online: the order is pending, then either delivered (resolved) or cancelled (rejected).

                    

                


                

                    

                        ⛓️
                        
Promise Chaining

                    

                    
Chain .then() calls to run async operations one after another. Each .then() returns a new Promise.

                    

                        
fetchUser(1)
  .then(user => fetchPosts(user.id))
  .then(posts => fetchComments(posts[0].id))
  .then(comments => console.log(comments))
  .catch(err => console.error(err))
  .finally(() => console.log("Done!"));

                    

                    

                        🌍 Real World
                        
Chaining is like an assembly line — each station does its work and passes the result to the next.

                    

                


                

                    

                        🏎️
                        
Promise.all & Promise.race

                    

                    
Run multiple promises concurrently:

                    
    
                        
  • Promise.all() — Waits for ALL to resolve
    • 
                        
  • Promise.race() — Returns the FIRST to settle
    • 
                        
  • Promise.allSettled() — Waits for ALL, regardless
    • 
                    

                    

                        
const p1 = Promise.resolve("Fast ⚡");
const p2 = new Promise(r => setTimeout(() => r("Slow 🐢"), 2000));

Promise.all([p1, p2])
  .then(results => console.log("All:", results));

Promise.race([p1, p2])
  .then(winner => console.log("Winner:", winner));

                    

                    

                        🌍 Real World
                        
Promise.all: Load user data + settings + preferences simultaneously. Promise.race: Timeout pattern for requests.

Module 5

                
Async / Await

                
Write asynchronous code that reads like synchronous code — cleaner & more intuitive.

            


            

                

                    

                        ⏸️
                        
async / await Basics

                    

                    
async makes a function return a Promise. await pauses execution until the Promise settles.

                    

                        
async function getUser() {
  const response = await fetch("/api/user");
  const data = await response.json();
  return data;
}

// Same as:
// getUser().then(data => ...)

                    

                    

                        🌍 Real World
                        
await is like standing in line — you wait for your turn (Promise resolution) before proceeding.

                    

                


                

                    

                        🛡️
                        
Error Handling

                    

                    
Use try...catch blocks to handle errors in async functions — much cleaner than .catch() chains.

                    

                        
async function fetchData() {
  try {
    const res = await fetch("/api/data");
    if (!res.ok) throw new Error("HTTP Error!");
    const data = await res.json();
    console.log(data);
  } catch (error) {
    console.error("Failed:", error.message);
  } finally {
    console.log("Cleanup done.");
  }
}

                    

                    

                        🌍 Real World
                        
Always wrap API calls in try/catch — networks fail, servers go down, data can be malformed.

                    

                


                

                    

                        🌐
                        
Real API Example

                    

                    
Fetch real data from a public API using async/await:

                    

                        
async function getRandomJoke() {
  try {
    const res = await fetch(
      "https://official-joke-api.appspot.com/random_joke"
    );
    const joke = await res.json();
    console.log(`😂 ${joke.setup}`);
    console.log(`👉 ${joke.punchline}`);
  } catch (err) {
    console.error("Failed to fetch joke");
  }
}

getRandomJoke();

                    

                    

                        🌍 Real World
                        
Every modern web app uses async/await: fetching user profiles, submitting forms, loading feeds — it's everywhere.

Module 6

                
DOM Manipulation

                
Interact with web pages dynamically — select elements, handle events & update content in real-time.

            


            

                

                    

                        🎯
                        
Selectors

                    

                    
Select HTML elements using various methods:

                    

                        
// Modern selectors (recommended)
document.querySelector(".my-class");
document.querySelectorAll("li");

// Classic selectors
document.getElementById("myId");
document.getElementsByClassName("myClass");
document.getElementsByTagName("div");

                    

                    

                        🌍 Real World
                        
querySelector is like CSS targeting — use the same selectors you already know from stylesheets.

                    

                


                

                    

                        🖱️
                        
Events

                    

                    
Listen for user interactions and respond dynamically:

                    

                        
const btn = document.querySelector("#myBtn");

btn.addEventListener("click", (e) => {
  console.log("Clicked!", e.target);
});

// Common events:
// click, dblclick, mouseover, mouseout
// keydown, keyup, input, change
// submit, focus, blur, scroll

                    

                    

                        🌍 Real World
                        
Every button, form, dropdown, and interactive element on the web uses event listeners.

                    

                


                

                    

                        ✏️
                        
Dynamic Updates

                    

                    
Modify page content, styles, and structure on the fly:

                    

                        
const el = document.querySelector("#box");

// Content
el.textContent = "New text";
el.innerHTML = "<strong>Bold</strong>";

// Styles
el.style.backgroundColor = "#3b82f6";
el.classList.add("active");
el.classList.toggle("hidden");

// Create elements
const newDiv = document.createElement("div");
newDiv.textContent = "I'm new!";
document.body.appendChild(newDiv);

                    

                    

                        🌍 Real World
                        
SPAs like Gmail, Twitter, and Notion update the DOM constantly without full page reloads.
